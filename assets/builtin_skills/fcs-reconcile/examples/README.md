# examples/

对账功能的演示数据与示例结果，用于教学和快速上手。

## 文件清单

| 文件 | 用途 |
|---|---|
| `对账演示数据.xlsx` | **教程输入数据**：左表（业务台账 12 行）+ 右表（银行流水 13 行）+ 差异说明，埋入 7 类典型对账差异 |
| `对账演示数据_对账结果.xlsx` | **对账结果示例**：7 张工作表（对账总览/待处理事项/已匹配/重复与冲突/数据质量/审计明细/运行参数），对齐输出契约 v1.0 |
| `gen_reconcile_demo.py` | 输入数据生成脚本——改数据改这个 |
| `gen_reconcile_result.py` | 对账结果生成脚本——改匹配逻辑改这个 |

## 重新生成

```bash
# 两个脚本路径基于自身位置，可从任意工作目录运行
python3 skills/fcs-reconcile/examples/gen_reconcile_demo.py     # 先生成输入
python3 skills/fcs-reconcile/examples/gen_reconcile_result.py   # 再生成结果
```

## 数据覆盖的 7 类对账差异

| 类型 | 场景 | 教学要点 |
|---|---|---|
| ① 完全匹配 | 金额/日期/编号一致 | 对账基线 |
| ② 金额不一致 | 5,800 vs 5,808 | 手续费/汇兑差，引出"金额容差" |
| ③ 一对多 | 台账一笔 12,000 ↔ 银行 8,000+4,000 | 按合计金额匹配 |
| ④ 多对一（未自动匹配） | 台账 3,500+2,500 ↔ 银行合并 6,000 | 银行附言无业务单号，纯主键匹配覆盖不到，需模糊匹配——天然的进阶钩子 |
| ⑤ 左表多余 | 台账有、银行无 | 在途/未到账 |
| ⑥ 右表多余 | 银行有、台账无 | 漏记账/手续费/利息/匿名收入 |
| ⑦ 日期错位 | 7/3 记账、7/4 入账 | 跨日对账的日期容差 |

> 设计取舍：④ 多对一刻意保留为"未自动匹配"状态，用于演示主键匹配的局限性。
