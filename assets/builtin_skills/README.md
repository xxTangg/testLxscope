**系统内置办公技能**

本目录随服务镜像部署，运行时不访问 GitHub 或 ClawHub。manifest.json 定义 10 个默认技能，sources.json 保存上游仓库、目录和固定提交；各目录保留原许可证，UPSTREAM.json 记录本地修改。

现有用户、新注册用户默认拥有这些技能。默认列表与用户的安装记录合并，只有显式卸载/恢复时写入存储；卸载以内置技能的禁用记录保存，重启与更新不重新启用。卸载不影响其他账号。用户可从技能页的“系统内置”来源重新安装。

首次查看会话技能或开始聊天时，服务把完整脚本、参考资料和模板复制到该会话的智能体技能目录。后续根据内容版本更新，或按当前用户的卸载记录移除。正在执行的聊天在下一轮应用变更。自行上传的同名技能不会被默认技能覆盖。内置技能卸载后的记录需要与其他账号数据一起持久保存。

安装清单只包含选型报告的10个优先候选。报销、合同审查和需要额外离线改造的图表等未包含。本次适配包括中文发现描述、会话内输出、宿主路径、内部素材来源和会议模板的输出参数；公文包移除了未确认分发授权的字体二进制并禁用下载脚本，使用部署环境已有字体名称。

Python及Office运行库在Dockerfile中预装。提示词和脚本都不要求任务期间安装依赖。Word、Excel、PPT、PDF可本地生成和做结构检查；当前镜像没有LibreOffice，像素级版式预览另需本地渲染服务。fcs-reconcile为上游Preview，先用于差异复核，不自动过账。

维护时替换选定目录并同步sources.json/UPSTREAM.json，保留许可声明。BuiltinSkillHub按实际内容计算版本；打包忽略__pycache__和字节码，避免运行缓存改变版本。不要修改技能的稳定name来发布同一技能的小更新，否则会产生新的默认项。

验证入口：tests/builtin_skills_test.py、tests/builtin_skill_runtime_test.py；还应运行原有hub_router与service_toolkit测试。依赖运行测试在隔离临时目录进行，脚本子进程禁止socket连接，检查文件内容与核对结果。
