# 占位符语法与格式化速查

## 占位符怎么写

在 Word 模板里，凡是要被 Excel 数据替换的地方，写成双大括号包名字：

```
{{占位符名}}
```

- 名字可中文可英文，不要带空格、不要带大括号本身。
- 同一个占位符可以在文档里出现多次，全部会被替换（正文段落 + 表格单元格都支持）。
- 名字必须和 Excel 第一列**完全一致**（含大小写、标点）。对不上就不替换，输出里会留下 `{{名}}` 原文。

示例模板片段：

```
致：{{客户名称}}
合同编号：{{合同编号}}        签订日期：{{签订日期}}
应付总额：{{合计}} 元         已付比例：{{已付比例}}
联系电话：{{联系电话}}
```

## Excel 数据怎么填

每个 sheet 三列，**按列序读取**（表头叫什么不影响，第 1 列=占位符，第 2 列=值，第 3 列=格式）：

| 第1列 占位符 | 第2列 值 | 第3列 格式 |
|---|---|---|
| 客户名称 | 北京华信科技有限公司 | text |
| 合同编号 | HT-2026-0088 | text |
| 签订日期 | 2026-06-02 | text |
| 合计 | 158600.5 | money |
| 已付比例 | 0.65 | pct |
| 联系电话 | 13800138000 | text |

- 第一列为空的行会被跳过（方便留空行分组）。
- 可以分多个 sheet，引擎会把所有 sheet 合并成一个大字典。重名以后出现的为准，尽量别重名。

## 格式（第三列）

| 格式 | 作用 | 输入 → 输出 |
|---|---|---|
| `money` | 金额：千分位 + 两位小数；负数用会计括号 | `158600.5` → `158,600.50`；`-1280` → `(1,280.00)` |
| `pct` | 百分比：小数 ×100 加 % | `0.65` → `65.00%`；`0.2963` → `29.63%` |
| `int` | 整数千分位 | `1200000` → `1,200,000` |
| `text` | 原样输出，不做任何数字处理 | `13800138000` → `13800138000` |
| 留空 | 自动：是数字→千分位两位小数；是文本→原样 | `1234.5` → `1,234.50` |

### 什么时候必须用 `text`

凡是"看起来像数字、但不是用来算的"，一律 `text`，否则会被当数字处理坏：

- 电话号码、手机号
- 身份证号、银行卡号
- 合同编号、订单号（带前导零的尤其要 text）
- 日期（除非你想自己控制格式）

不用 text 的后果：`13800138000` 可能变成 `1.38E+10` 或 `13,800,138,000`。

## 常见坑

| 现象 | 原因 / 解决 |
|---|---|
| 输出里还有 `{{某某}}` | Excel 占位符名和模板对不上，检查空格、错别字、全半角 |
| 编号/电话被加了千分位或变科学计数 | 那一行第三列填 `text` |
| 金额没千分位 | 那一行第三列填 `money` |
| 百分比显示成 `0.65` 而不是 `65.00%` | 第三列填 `pct`，且 Excel 里存的是小数 0.65（不是 65） |
| 负数没括号 | 用 `money` 格式才有会计括号；普通数字不加 |
