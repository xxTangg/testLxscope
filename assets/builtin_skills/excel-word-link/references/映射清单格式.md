# mapping.json 字段详解

`apply_mapping.py` 吃的「对应关系清单」。顶层是数组，每条描述「往哪填、填什么、怎么格式化」。

```bash
python3 scripts/apply_mapping.py mapping.json word.docx 输出.docx
```

## 一条记录的字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `locate` | 是 | 定位：填到 Word 哪里。三种 type，见下 |
| `source` | 取值二选一 | 从 Excel 现取值，**推荐**（换数据不用改 mapping）。见「取值」 |
| `value` | 取值二选一 | 写死的常量，适合极少变的固定文字 |
| `format` | 否 | `money` / `pct` / `int` / `text` / 留空自动 |
| `note` | 否 | 人类可读说明，会在命中/未命中报告里显示，**强烈建议写**（便于人工检查） |

> 有 `source` 就从 Excel 现取（换数据自动更新）；否则用 `value`。**模板固定、每期换数据的场景一律用 source**，mapping 才能复用。

## 取值：source（从 Excel 取，推荐）

填充时用 `--excel 数据.xlsx`，脚本按 source 现取值。两种写法：

```json
{"source": {"sheet": "基本信息", "key": "客户名称"}}        // 在该 sheet 第一列找 "客户名称"，取同行第二列
{"source": {"sheet": "基本信息", "key": "客户名称", "col": 3}}  // 取同行第 3 列（col 1 起）
{"source": {"sheet": "明细", "row": 2, "col": 2}}            // 直接坐标，row/col 都 1 起（和 inspect 的 R 行号一致）
```

- `key` 式：适合「字段名 | 值」两列的 key-value 表。
- 坐标式：适合规整数据表。
- 取不到值（sheet 不存在 / key 没找到）会在报告里标「Excel 取值失败」。
- **派生值**（合计/占比/同比这类要算的）source 取不了，得先在 Excel 用公式算好，或走 `进阶范例-财务附注/` 的计算脚本。

## 三种定位（locate.type）

### 1. cell —— 表格坐标（最可靠）

坐标用 `inspect_files.py` 输出的 `T{table}R{row}C{col}`。

```json
{"locate": {"type": "cell", "table": 0, "row": 1, "col": 1}, "value": 140000, "format": "money"}
```

- 不给 `old`：整格设为 value（**填空**场景，单元格原本是空的）。
- 给 `old`：只替换格内的 old 文本（格里原本有旧值/占位文本时用）。

```json
{"locate": {"type": "cell", "table": 0, "row": 1, "col": 1, "old": "0.00"}, "value": 140000, "format": "money"}
```

### 2. find —— 正文查找替换

```json
{"locate": {"type": "find", "old": "0.00", "para": 3}, "value": 158600.5, "format": "money"}
```

- `old`：Word 里现在的文本（下划线 `________`、占位 `XXX`、旧值 `0.00` 等）。
- `para`：限定在第几个段落（`inspect` 的 `P{n}` 的 n）。**重复文本必须给 para**，否则只命中全文第一个。
- 不给 `para`：全文（正文 + 表格）找第一个匹配。

### 3. placeholder —— 兼容旧占位符

```json
{"locate": {"type": "placeholder", "name": "公司名"}, "value": "北京华信", "format": "text"}
```

替换文档里所有写法为 `{{公司名}}` 的地方（找第一个命中处）。仅当模板本来就用了 `{{}}` 时用。

## format 取值

| 值 | 作用 | 例 |
|---|---|---|
| `money` | 千分位两位小数，负数会计括号 | `158600.5` → `158,600.50`；`-1280` → `(1,280.00)` |
| `pct` | 小数转百分比 | `0.65` → `65.00%` |
| `int` | 整数千分位 | `1200000` → `1,200,000` |
| `text` | 原样（编号/电话/身份证号必须用，否则被当数字算坏） | `13800138000` → `13800138000` |
| 留空 | 数字→千分位两位；文本→原样 | — |

## 运行后看什么

脚本会报告三类结果：

- **命中 N 条 / 共 M 条**：M > N 说明有没填上的。
- **未命中**：定位没找到。检查坐标对不对、`old` 原文是否一字不差（含全半角空格）。
- **格式合并**：该处文字跨多个 run，替换时合并到首 run，段内混合格式可能丢——目检该处。

## 模板变动检测（--check）

模板被人微调后，先跑 `--check` 看哪几条对不上，只补差异，不用从头审：

```bash
python3 scripts/apply_mapping.py mapping.json 微调后.docx --check --excel 数据.xlsx
```

输出例：`检测：5 条仍命中 / 共 6 条` + 标出对不上的那条及原因（坐标越界 / 找不到原文 / Excel 取值失败）。

## 完整示例（用 source，可复用）

```json
[
  {"locate": {"type": "find", "old": "________", "para": 1},
   "source": {"sheet": "基本信息", "key": "客户名称"}, "format": "text", "note": "P1 收件方"},
  {"locate": {"type": "find", "old": "HT-XXXX-XXXX", "para": 2},
   "source": {"sheet": "基本信息", "key": "合同编号"}, "format": "text", "note": "P2 合同编号"},
  {"locate": {"type": "find", "old": "0.00", "para": 3},
   "source": {"sheet": "基本信息", "key": "应付金额"}, "format": "money", "note": "P3 应付金额"},
  {"locate": {"type": "cell", "table": 0, "row": 1, "col": 1},
   "source": {"sheet": "明细", "key": "货款"}, "format": "money", "note": "表0货款（填空）"}
]
```

跑：`python3 scripts/apply_mapping.py mapping.json word.docx 输出.docx --excel 数据.xlsx`
换数据时这份 mapping 一字不用改。
